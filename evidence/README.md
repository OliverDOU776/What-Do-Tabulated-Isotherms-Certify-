# Curated results

`published_results.csv` holds the manuscript's three result tables in long form (held-out extrapolation, known truth,
real pairs). `published_results.json` maps every number quoted in the manuscript text to its value, keyed by the
manuscript's macro name (for example `HoCovAll` = 97.0%, the held-out coverage of the Langmuir-site class).

These are publication-level summaries generated by the paper pipeline from its saved experiment outputs. They are
not raw run logs, and they are separate from the explorer data in `docs/explorer/data/`, which are recomputed by
`scripts/build_explorer_data.py` for a sample of records.
